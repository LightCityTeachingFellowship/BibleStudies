## Download the recordings

1. Sign into YouTube Studio with the account that owns these uploads.
2. Open each Studio link below. Use the video options menu to Download. If Download is not shown on the edit screen, use Studio > Content, locate that video, and open its three-dot menu.
3. Rename each downloaded MP4 to the exact filename in the table.
4. Put the files in the input folder next to this checklist: `tools/audio-pilot/input/`.
5. Keep the files here for the trial; there is no need to attach them to chat.

## Trial after the downloads

- Read actual durations and source sizes, then compare 64 kbps mono and 96 kbps stereo audio.
- Measure processing time and output sizes before extrapolating costs to the full library.
- Compare speech, prayers, singing, quiet sections and noisy sections.
- Test audio in foreground, minimized and screen-locked states on target devices once a pilot player is ready.
- Preserve the mapping to each YouTube ID and existing membership setting.

## Current boundary

No recordings have been downloaded or converted yet. No hosting has been purchased, and nothing from this pilot is published on the website. Media input/output are ignored by Git, and the whole tools directory is excluded from Jekyll publication.

The video files may be large. YouTube Studio provides copies at the resolution it makes available; we are evaluating audio quality rather than video quality. Do not repeatedly download all 1,000 recordings for this first trial.
