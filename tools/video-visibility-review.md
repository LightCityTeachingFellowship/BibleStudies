## Adding or changing videos

Paste one ID per line at the top of _includes/video-ids-public.txt for a public video, or _includes/video-ids-members.txt for a members-only video. Save, then commit and sync as usual. No terminal command, title or JSON editing is required. To change visibility, move the ID between the lists. If duplicated across lists, Members takes priority.

The website loads titles and categories automatically, even when an ID is not yet in the metadata cache. Existing video order is retained; newly pasted IDs appear first. _data/videos.json is a metadata cache, not the editing list.
